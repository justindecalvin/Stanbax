**Solution:**

1. Clone your repo locally (outside of Replit).
2. Delete the existing `package-lock.json`:
   ```bash
   rm package-lock.json
   ```
3. Reinstall dependencies to generate a clean lockfile:
   ```bash
   npm install
   ```
4. Commit and push the updated `package-lock.json`:
   ```bash
   git add package-lock.json
   git commit -m "Regenerate package-lock.json with standard npm registry URLs"
   git push
   ```

This will ensure the lockfile references `https://registry.npmjs.org` instead of Replit's internal proxy, allowing Netlify to resolve and download packages successfully.
